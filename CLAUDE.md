# tui-canvas

Persistent canvas display panel for Claude Code sessions. A Go binary that is simultaneously a TUI client, a background daemon, and a Claude Code plugin.

See [ARCHITECTURE.md](ARCHITECTURE.md) for a full explanation of the three-part system.

## Build & Install

```bash
make build    # produces ./tui-canvas binary
make install  # builds + installs to ~/.local/bin/tui-canvas
make test     # go test ./...
make clean    # removes ./tui-canvas
```

Always use `make build` / `make install` rather than calling `go build` directly.

After `make install`, the running daemon must be restarted to pick up binary changes — the daemon auto-starts when the TUI is launched.

## Repository Layout

```
cmd/tui-canvas/main.go       entry point; subcommand dispatch
internal/
  daemon/daemon.go            background state server
  protocol/protocol.go        shared message types + socket path
  tui/
    model.go                  bubbletea model + update logic
    view.go                   rendering (tab bar, viewport, help bar)
plugin/
  .claude-plugin/plugin.json  plugin manifest
  hooks/
    hooks.json                SessionStart hook declaration
    session-start             bash script: registers session, emits session ID
  skills/
    tui-canvas/SKILL.md       /tui-canvas skill (send content to canvas)
    tui-clear/SKILL.md        /tui-clear skill (clear canvas)
```

## Key Libraries

- **bubbletea** (`github.com/charmbracelet/bubbletea`) — TUI event loop and model
- **bubbles/viewport** (`github.com/charmbracelet/bubbles`) — scrollable content pane
- **glamour** (`github.com/charmbracelet/glamour`) — markdown → terminal rendering
- **lipgloss** (`github.com/charmbracelet/lipgloss`) — terminal styling

## Plugin State File

The daemon persists session registrations to `~/.local/share/tui-canvas/sessions.json` and reloads on startup. Do not edit this file manually.

## Common Tasks

**Finding the session ID after `/clear`:** run `tui-canvas list --cwd "$(pwd)"` — returns tab-separated `id name cwd` rows. Or press `?` in the TUI to toggle debug mode, which shows session IDs inline.

**Sending content to the canvas:**
```bash
python3 -c "
import json, subprocess
msg = json.dumps({'type': 'canvas_append', 'session_id': 'SESSION_ID', 'content': 'markdown here'})
subprocess.run(['tui-canvas', 'send'], input=msg.encode())
"
```
